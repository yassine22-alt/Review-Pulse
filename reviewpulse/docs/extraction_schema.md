# Extraction schema

> Generated by `python scripts/gen_docs.py` from `src/reviewpulse/schema.py`; do not edit by hand.
> Schema version 0.1. JSON Schema files: `schemas/*.schema.json`.

## The three files

| file | model | written by | read by |
|---|---|---|---|
| `sheet_<n>.json` | `Sheet` | Reader: ingest + annotate (what was drawn) | Interpreter |
| `building_<n>.json` | `BuildingModel` | Interpreter: perception (what it means) | Judge, reports, app |
| `findings.json` | list of `Finding` | Judge: rules engine (what is wrong) | reports, app |

## Conventions (the intermediate-representation decisions, task B3)

1. **Coordinates.** Sheet space, y axis up, origin at the sheet's lower-left corner (D6).
   Raster and PDF pages are mapped there by an affine transform at ingest.
2. **Units.** Paper millimetres for PDF, SVG and raster sheets; drawing units for DXF
   (`Sheet.coord_unit`). Real metres exist only through `Sheet.scale.metres_per_unit`, and every
   metric value in the model (`width_m`, `area_m2`, ...) is derived from it. `None` means unknown and
   metric rules are then NOT_EVALUATED, never guessed.
3. **Scale provenance.** `Scale.method` says how it was found. Only `dxf_units`, `dimension_consensus`,
   `user` and `scale_bar` count as verified; `symbol_prior` (door-size or wall-thickness prior) is an
   estimate and caps metric verdicts at WARNING.
4. **Uncertainty.** Three levels: `Prov.confidence` per value; `Element.confirmed` /
   `attrs.needs_confirmation` per element; `BuildingModel.tier` per model (T1 exact vector with a
   verified scale, T2 partly estimated, T3 estimated). A FAIL needs T1 or confirmed deciding elements;
   otherwise the verdict is WARNING with the reason (engine/policy.py).
5. **Provenance.** Every primitive, text, dimension, element, room and edge carries `Prov`: input kind,
   producing stage and version, confidence and stage evidence. Elements list the primitives they were
   built from (`member_ids`), so every finding can be traced back to drawn marks.
6. **Versioning.** Files carry `schema_version`; loaders refuse an unknown major version.

### Primitive

One drawn mark as found in the file: line, arc, polyline, polygon or circle.

| field | type | default | meaning |
|---|---|---|---|
| `id` | `str` | required | Stable id, unique within the sheet. |
| `kind` | `Literal['line', 'arc', 'polyline', 'polygon', 'circle']` | required | Geometry kind. |
| `pts` | `list[tuple[float, float]]` | [] | Line: 2 points; polyline / polygon: n points (a polygon is implicitly closed). |
| `center` | `tuple[float, float] \| None` | None | Arc / circle centre. |
| `radius` | `float \| None` | None | Arc / circle radius, sheet units. |
| `a0` | `float \| None` | None | Arc start angle, degrees counter-clockwise from +x. |
| `a1` | `float \| None` | None | Arc end angle, degrees counter-clockwise from +x. |
| `layer` | `str \| None` | None | CAD layer, PDF optional-content group or SVG group, when the file has one. |
| `width` | `float \| None` | None | Stroke width, sheet units. |
| `color` | `str \| None` | None | Stroke colour as written in the file. |
| `dashed` | `bool` | False | Drawn with a dash pattern. |
| `filled` | `bool` | False | Filled region (solid hatch, filled PDF path). |
| `block` | `str \| None` | None | DXF block name, or `dim:<id>` for dimension graphics. |
| `hidden` | `bool` | False | Superseded by a derived primitive (e.g. segments replaced by a fitted arc). |
| `prov` | `Prov` | required |  |

### Scale

| field | type | default | meaning |
|---|---|---|---|
| `metres_per_unit` | `float \| None` | None | Metres per sheet unit; None = unknown. |
| `method` | `Literal['dxf_units', 'dimension_consensus', 'title_block', 'scale_bar', 'user', 'symbol_prior', 'none']` | 'none' | How the scale was obtained. `dxf_units`, `dimension_consensus`, `user` and `scale_bar` count as verified. |

| `n_candidates` | `int` | 0 | Dimension candidates considered. |
| `n_inliers` | `int` | 0 | Candidates agreeing with the chosen scale. |

### Prov

Where a value came from and how sure the stage that produced it is.

| field | type | default | meaning |
|---|---|---|---|
| `source` | `Literal['vector', 'raster', 'ocr', 'user', 'derived']` | required | Kind of input the value was read or derived from. |
| `stage` | `str` | required | Producing stage and version, e.g. `pdf_extract`, `walls_pairs_v1`. |
| `confidence` | `float` | 1.0 | Stage confidence in [0, 1]; a calibrated probability only where the stage says so. |
| `evidence` | `dict` | {} | Stage-specific evidence, e.g. `{"layer": "A-WALL"}`; classifier probabilities `p_wall`, `p_door`; dataset ground truth under `gt` (evaluation only). |

## Element attributes (`Element.attrs`)

Checked on pipeline output by `schema.check_attrs` (tests/golden/test_contract.py): an unknown
key or a wrong value type fails the build.

**wall**

| key | type | meaning |
|---|---|---|
| `candidate` | bool | Below the acceptance score (cls `other`). |
| `source` | str | `pairs`, `filled`, `thick_line`, `learned_face`, `raster`... |
| `thickness_m` | float or int | Thickness in metres. |
| `thickness_px` | float or int | Thickness in pixels (raster). |
| `connected` | list | [start, end]: joined to another wall. |
| `confirmed_by` | str | `user`, or the calibrated threshold that confirmed the element. |
| `needs_confirmation` | bool | Estimated element: findings on it stay WARNING until confirmed. |

**other**: same keys as `wall`.

**door**

| key | type | meaning |
|---|---|---|
| `width_m` | float or int or None | Clear width in metres (None when the scale is unknown). |
| `mid` | tuple or list | Opening midpoint on the wall axis, sheet units. |
| `normal` | tuple or list | Unit normal of the host wall at the opening. |
| `thickness` | float or int | Host wall thickness, sheet units. |
| `wall_id` | str or None | Host wall element. |
| `wall_ids` | list | Walls on both sides of the gap. |
| `jambs` | list | The two jamb points of the gap. |
| `block` | str | DXF block the opening was inserted as. |
| `glazing_lines` | int | Glazing lines found across the gap (windows). |
| `rooms` | list | [room on one side, room on the other] (None = outside), set by R10. |
| `tag_text_id` | str | Text item of the associated schedule tag. |
| `source` | str | Producer when not the vector rules: `raster`, `learned`. |
| `carried` | bool | Kept from the rule pass and re-hosted on the learned-pass walls. |
| `confirmed_by` | str | `user`, or the calibrated threshold that confirmed the element. |
| `needs_confirmation` | bool | Estimated element: findings on it stay WARNING until confirmed. |
| `hinge` | tuple or list | Hinge point, sheet units. |
| `hinges` | list | Both hinge points of a double door. |
| `radius` | float or int | Swing radius, sheet units. |
| `double` | bool | Double-leaf door. |
| `swing_polygon` | list | Area swept by the leaf (or leaves), sheet units. |
| `leaf_swings` | list | Area swept by each leaf of a double door. |
| `swing_side` | int | +1 / -1: side of the wall normal the door opens to. |
| `width_source` | str | `arc_radius` / `arc_radii`: how the width was measured. |
| `no_gap` | bool | Door symbol found with no wall gap (wall drawn through). |

| `thickness` | float or int | Host wall thickness, sheet units. |
| `wall_id` | str or None | Host wall element. |
| `wall_ids` | list | Walls on both sides of the gap. |
| `jambs` | list | The two jamb points of the gap. |
