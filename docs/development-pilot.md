# Development pilot before the full run

The order is data in `reports/development-pilot.json`, not a clause-specific
extractor branch. Both arms receive the same selected source cases and use
Gemini 4 Hydrogen, temperature zero, an 8,192-token output budget, 180-second
request timeout and 13-second pacing. The original interpreter remains fixed.
Redesigned code versions are recorded separately; results from changed
versions will not be combined as one paired comparison.

First run T01, T04, T06, T09 and T13 on both arms. Then run M03, M04, M05 and
M06, followed by A03, A05 and A08. The three selected accessibility obligations
are executable algebraically under the frozen scope: a width range and two
count ratios. Their frozen labels say evidence is missing, not that a new
computation or specialist judgment is required. This does not assert that
the present drafting catalogue already has the necessary entity/fact bindings.

The worker sends a phase's ID list through a generic selection argument. It
cannot drift into later cases while finishing a phase. Once both thermal sets
are complete, zero retained rules in both arms triggers WAITING_FOR_DIAGNOSIS.
A checkpoint must record the terminal-stage diagnosis, model, both code
fingerprints and an explicit continuation decision before later phases run.
This pause is about retention, not a claim that retained rules are correct.

At configuration time the pilot has 0/12 completed evaluations per arm because
the current allowance is exhausted. These are pending cases, not semantic
failures. No matches, partial matches, wrong-rule rate or accuracy improvement
can be claimed yet. Wrong approvable / approvable is undefined (0/0).

Reports will list the frozen reading next to each retained candidate, terminal
stage, author classification and differences. Retention and correctness must
be separate. API-unavailable and client-budget interruptions are excluded from
semantic denominators. Author labels have no independent review. The sealed
fourth document remains untouched and unrun.
