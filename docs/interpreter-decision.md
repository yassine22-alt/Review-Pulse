# Interpreter decision: pending measurement

The requested decision cannot yet be made. There are **0/5** usable strong-model
thermal outputs from the scope-separated pilot and **0/0** scored thermal
slots. HTTP 503, HTTP 400 and HTTP 429 are request outcomes, not evidence of
low model accuracy. The 1.5B negative result cannot substitute for this test.

The predeclared decision uses all five structured thermal pilot outputs and
seven eligible fields each: **35 field judgements**. It uses the initial draft,
before deterministic validators, without selecting the best attempt. The
current metric is normalized exact slot-set agreement against author labels;
it does not measure correct associations between fields or legal equivalence.
Seventy percent is a research direction criterion, not an acceptance threshold
for automated regulatory decisions. Human approval remains required.

If agreement is below 70%, the next report must recommend an assisted drafter:
the model proposes source-linked fields, a reviewer corrects meaning, and the
checker evaluates only reviewed rules with sufficient evidence. The model
must not silently approve its own interpretation or fill missing observations.
That recommendation has **not** been triggered by the current missing data.

The associated evaluation should measure the work the proposal saves. Freeze
the candidate once and have a reviewer edit it without seeing the arm or
validator result. Count additions, deletions and replacements of semantic
fields; count connective/quantifier/link corrections separately because a
correct set of fields can still form a wrong rule. Equivalent unit conversions
are not semantic edits. A missing usable proposal counts as a whole-clause
rewrite, never an excluded case. Evidence requests and context retrieval are
reported separately from interpretation edits: a reviewer may not invent a
missing fact merely to finish a clause.

Report median and distribution of edits per reviewed clause, zero-edit clauses
over all reviewed clauses, whole-clause rewrites over all reviewed clauses,
review time per clause, and residual wrong-approved interpretations over all
approved interpretations. Compare review time with authoring the same clauses
without a proposal. An independent reviewer should adjudicate disagreements;
the current author-only labels do not provide that independence.

If agreement is at least 70%, propose a paired whole-rule measurement next:
scope and field associations, behavioral boundary/exception cases, and
resulting false passes and confirmed-violation precision on the same plans.
High slot agreement alone is insufficient. No new checker capability should
be built on that number. Neither branch is selected yet, and the fourth
document remains sealed and unrun.
